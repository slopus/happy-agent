# Native Live

Voice and desktop inference are separate provider lifetimes. The controller freezes the configured default route before the selected voice credential can allocate a call. Its fresh inference session has only the nine original desktop tools and zero inference retries. Desktop actions use the revisioned control protocol and require an actual result; staging a message never sends it or supplies human authorization.

An SDP offer and its selected credential stay process-private. The original durable `attempted` checkpoint commits before allocation. Recovery marks every nonterminal stored session failed and cannot allocate again, even when a durable invocation survives a daemon restart. Reusing a session identity conflicts; another owner's identity remains invisible.

Public GPT-Live and native Codex subscription transport are distinct dialects. Each uses its official allocation endpoint and passive attach path. Neither falls back or replays. Only public provider usage is billed; native transcript events do not invent usage. Closure is successful only after readiness and explicit provider closure proof. Unexpected disconnects stay failed.

Desktop input, provider events, transcript history, selected session updates, outstanding actions, and outgoing control frames have explicit bounds. An unknown action result, conflicting completed result, same-revision context conflict, or inaccessible conversation update ends the call safely. Logs contain fixed error categories and identities, never credentials, transcripts, or desktop contents.

Disposal has an explicit signal that always participates in the actor's wait. A conditional cancellation branch can be disabled while the actor is owned and never wake after that state changes; the separate disposal signal releases an idle actor and permits startup recovery without replaying allocation.
