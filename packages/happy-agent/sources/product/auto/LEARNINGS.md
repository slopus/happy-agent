# Native Auto learnings

Human authorization comes only from a positive `messageOrigin: "user"` marker
at the original input hook or the separately retained human portion of an
interactive answer. Missing metadata, an agent collaboration message, shell
output and a model's claims remain untrusted. The native classifiers are checked
against expectations generated by the original source functions.

Original archive integrity cannot prove complete human evidence in any
generation. The context-erasure hook discarded earlier authorization, and the
interactive-answer bridge could silently lose an answer while leaving the
archive healthy. Answered request rows do not retain the answering actor, so
they cannot reconstruct human authorization. The native archive retains the
original first migration and requires a native completeness marker for every
persisted generation, committed only for a genuinely recreated identity.
Ambiguous historical evidence remains intact and reviews fail as unproven.
Missing archives, inconsistent flags, position gaps and count mismatches also
fail closed.

Compaction and model selection must preserve the human archive. They never
recreate its identity or clear its poison. Archive writes and one-time answer
consumption participate in their caller's transaction, and poison recovery is
published only after commit. Recovery clears only the poison epoch observed by
identity recreation; a later evidence failure in the same transaction survives
that callback, even when its durable poison write failed.

The original transcript builder prioritizes human messages and selected answers
under its bounded UTF-16 budget. Its exact original output remains a pure
reference step. The current permission policy additionally refuses an allow
when required human evidence was skipped, truncated before storage or omitted
by that budget. An omitted-evidence flag is never merely display metadata for
an executing approval.

These helpers are currently verified outside daemon startup. They do not yet
install the private reviewer, tool policies, scoped elevation or refusal circuit.

A verdict comes only from normally completed trailing reviewer text. Contiguous
final text blocks join in order; a later thinking block or tool result ends that
sequence so an earlier allow cannot survive as the final answer. Captures keep
only the newest sixty bounded entries while preserving summed usage separately,
including optional reasoning tokens. The private model routes, stable reviewer
identity, policy with additional security rules and capture bounds match
expectations generated by their original source functions.
