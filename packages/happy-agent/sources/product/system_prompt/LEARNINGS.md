# System prompt learnings

The native module captures the original product prompt templates and TypeBox schemas. Model IDs choose their own prompt before provider family fallback; the Happy identity is substituted without editing the vendor reference files. The environment and visible model routes are rebuilt for each inference.

Instruction documents belong to the agent's compute. Discovery uses the public compute filesystem seam for the nearest Git root, root security rules, and each AGENTS.md from root to working directory. Configuration owns the separate global instruction path and reads it fresh with the original UTF-8 oversize sentinel. A missing Git root limits project discovery to the working directory. Symbolic document links remain errors, while oversized files become bounded omission records.

The first Source comparison exposed two adapter mistakes: a missing file was validated as a runner wire stat object, and an oversized global document retained a BOM that Source's streaming decoder removes. The compute owner now represents missing paths internally before wire-object validation; Source wire schemas remain unchanged. The global reader preserves Source's streaming behavior, including complete replacement characters and an incomplete trailing code point.

The module prepares instruction changes for Base's durable steering queue. A run snapshot keeps the prompt and its replacement notice consistent; a pending notice retains its identity until accepted. The delivered fingerprint changes only in the transaction accepting the matching hidden system steering message. Automatic permission review reads the live formatted snapshot without touching that delivery state. Durable Functions remains a feature dependency; no independent recovery loop or worker is needed because Base owns notice delivery and replay. Automatic notice dispatch still requires the pending native beforeTurn hook; its inference test is explicitly skipped until that hook can be integrated. Fresh document delivery and the complete notice state transitions are verified separately.
