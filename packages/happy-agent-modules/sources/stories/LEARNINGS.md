# Stories learnings

## Activity replaces Stories

Stories duplicated the updates people can follow through Activity. Kirill requested deleting
the feature from Desktop and Happy Agent. The runtime no longer loads Stories, offers its tools,
instructs agents to post, serves its routes, or publishes its events. Old opt-in settings cannot
enable it. A Stories-like feed may return for the latest updates in Activity.

Retirement preserves stored rows, media, immutable migration definitions, and historical message
quotes and still frames. Published client protocol types remain readable for older daemons;
current bootstrap and bot responses retain disabled compatibility fields.
