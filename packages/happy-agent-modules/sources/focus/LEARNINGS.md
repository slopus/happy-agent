# Focus — learnings

## Focus is not a subtask

Focus started as a subtask of the built-in bot. In team mode that bot is shared, so every
member saw every member's Focus as a "Focus" sub-row under it, could open it, and could read
that person's whole task list in its brief. Focus is now an unlisted agent of the built-in bot,
created through the collaboration module without reporting back. It sits in no `subtasks` tree,
so no one sees it as a sub-row. It still runs on the installation's default model and is briefed
the same way.
