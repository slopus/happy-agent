# Gen UI

Gen UI is a small, fixed vocabulary of UI components that a model writes as
JSON and every Happy client renders with its own native widgets. The model
says what to show; the client decides how it looks.

| File | For | What it is |
|---|---|---|
| [USAGE.md](USAGE.md) | models and people writing documents | How to write a good Gen UI document |
| [SPEC.md](SPEC.md) | people building renderers and hosts | Document format, rules every renderer follows |
| [RENDER.md](RENDER.md) | people building the compiler and clients | Draft: the second, lower-level schema clients draw, and how the daemon compiles to it |
| [render/catalog.json](render/catalog.json) | tools | The 15 render primitives |
| [theme.json](theme.json) | clients | Shared colours: tone inks and fills, chart palette, light and dark |
| [icons/](icons/) | clients | Shared icon set: one black-on-transparent PNG (1x, 2x, 3x) and SVG per icon name |
| [components/](components/) | both | One page per component: props and behaviour |
| [catalog.json](catalog.json) | tools | The catalog: every component, prop, enum and limit. Source of truth |
| [genui.schema.json](genui.schema.json) | tools | JSON Schema (2020-12) for a document, generated from the catalog |
| [examples/](examples/) | both | Valid documents, also used as renderer fixtures |

`catalog.json` holds everything, including each component's behaviour text
and example. `genui.schema.json`, `components/*.md` and `examples/` are
generated from the same definition. Change the definition and rebuild; do not edit
them by hand.

`theme.json` and `icons/` are generated by `gen/build_shared.py` in the task folder they were
designed in, from the `lucide-static` 0.460.0 tarball rendered with `rsvg-convert`. They are
committed as generated; `pnpm genui:build` does not rebuild them.

The entry file is `index.genui.json`, served as plain `application/json`. Clients recognise
Gen UI by the artifact or vault app `type`, `gen_ui`, not by a media type.
